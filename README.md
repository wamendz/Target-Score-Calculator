# TaskTrack: A Student Assignment Tracking System

## Overview

**TaskTrack** is a simple Python program designed to help students organize, monitor, and manage their assignments across different subjects. It allows users to keep track of assignment details, check completion status, and identify overdue tasks.

## Features

* **Add Subject** – Add and manage different subjects.
* **Add Assignment** – Add an assignment with its subject, title, and due date.
* **View All Assignments** – Display all saved assignments.
* **View Assignments by Subject** – View assignments under a selected subject.
* **Mark Assignment as Completed** – Update an assignment's completion status.
* **Delete Assignment** – Remove assignments that are no longer needed.
* **View Overdue Assignments** – Identify assignments that have passed their due dates.
* **Exit** – Close the program.
